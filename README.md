# Rishabh The Series

Portfolio site rebuilt with **Vite + React**. Same streaming-service look and content as the original single-page HTML.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://127.0.0.1:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Project layout

- `src/data.js` — all resume content (edit here for text updates)
- `src/components/` — Intro, Who's watching, Nav, sections, modal
- `public/img/` — photos
- `public/Rishabh_Kushwaha_Resume.pdf` — resume download
- `legacy/` — original `index.html` backup
